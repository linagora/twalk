# Twalk ships no default LLM, and the operator configures one through the Companion

A persona refuses to start without an LLM endpoint: there is no default, and nothing is ever sent to a model the operator did not name. The configuration — an OpenAI-compatible base URL, a model name, a credential, and a free-form object of provider parameters passed through untouched — is held by the Companion Gateway, set from the Companion, and **injected by the Hermes runtime into each persona's environment** when it spawns it. A credential supplied by the operator as a file wins over one set from the browser, so a production stack can lock it down. The system prompt stays in the persona's code, versioned and reviewed; only the model and its parameters are configuration.

Rationale: a sovereign product must not choose where the user's messages go, and a refusal to start says that clearly where a silent default would not. The configuration lives in the Gateway because the Companion must be able to change a model without shell access, and because the Gateway is already the deployment's single authority for read-your-own-state (ADR 0010, ADR 0011). The runtime injects it rather than letting each persona fetch it, because the Gateway's service token also opens the consent snapshot — the list of every contact — and a third-party persona, which the platform deliberately treats like a first-party one (ADR 0008), has no business holding that to learn which model to call. The provider parameter passthrough exists because providers differ in what they reject: the first endpoint tried in practice, OVH's AI Endpoints, needed fields dropped that OpenAI clients send by default, and without a passthrough Twalk would simply not work with it. Bundling an inference server was rejected: it would make the milestone download gigabytes and answer in minutes on a host without a GPU. The system prompt is not configuration because it *is* the agent's behaviour — editable from a browser, two deployments running the same code would behave differently with no audit trail.
