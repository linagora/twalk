# A persona's reply discloses itself to the contact (#121) — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every reply a persona drafted reaches the contact with one sentence after it, on a line of its own, in the language the reply was written in — *"Rédigé avec mon assistant IA."* / *"Drafted with my AI assistant."* — on by default; turning it off is a dated, attributed, append-only record; a message the user wrote themselves carries nothing; a reply whose language has no sentence is no suggestion at all, named and counted.

**Architecture (ADR 0019, ADR 0031, with the gaps closed here):** The **five sentences live in the contract** — `contracts/disclosure/v1/sentences.json` (CC0, "if a component and the contract disagree, the contract wins") — and both the SDK (a Python copy pinned by a test to the contract file) and the Companion Gateway (`include_str!`) read them. Two v1 schemas gain the optional member `data.disclosure` (the sentence itself, never inside `body`) — the deliberate exception ADR 0031 records. On the **SDK path** the persona learns the language it wrote in by **asking its model once more**, a one-token-shaped question (ADR 0016: detection is the model's job, never a library); an answer outside the five is a named, non-transient refusal — no suggestion. On the **Hermes path** the Gateway maps Hermes's BCP-47 tag to its primary subtag and refuses one outside the five with a counted `422`. The Gateway **appends** the sentence to `final.body` at approval (`body + "\n" + sentence`) when the switch is on, carries it as `data.disclosure` on `persona.reply.approved`, and omits both when off; `edited` keeps comparing the body alone. The **switch** is an append-only journal of its own in the Gateway's store (`disclosure_decision`: `new_state`, `occurred_at`, `actor`, `reason`), sibling of the consent journal, default on, read as its last row; `GET/PUT /api/settings/disclosure`. The Sensor posts `final.body` verbatim, so nothing changes there. The Companion shows the sentence, fixed, beside the editable body on the approval screen — or says the switch is off and since when — and a card on the settings screen with the switch and the record.

**Tech Stack:** JSON Schema (contract), Python stdlib (SDK), Rust/axum/rusqlite (Gateway), SvelteKit (Companion), the existing stacks and stubs.

**Spec:** GitHub #121 (mirror `.scratch/hermes/ticket-121.md`), ADR 0019, ADR 0031 (amended by Task 6 with one paragraph: the sentences' authority is the contract file; the Hermes path's tag mapping). Facts: `/tmp/…/scratchpad/facts-121.md` (copied to the workspace as `facts.md`).

## Global Constraints

- **The sentences** (exact): `en` "Drafted with my AI assistant." · `fr` "Rédigé avec mon assistant IA." · `it` "Scritto con il mio assistente IA." · `es` "Redactado con mi asistente de IA." · `de` "Verfasst mit meinem KI-Assistenten." — plain text, one line, no product name, "AI" said plainly.
- **The member**: `data.disclosure`, `type: string`, `minLength: 1`, `maxLength: 200`, optional, on `persona.suggest.produced.v1` and `persona.reply.approved.v1`; both fixtures carry the French sentence; the approved fixture's `final.body` becomes `"Pas de problème, à 20h ! 👍\nRédigé avec mon assistant IA."`.
- **Deterministic ids are unchanged** (the suggestion id hashes persona/trigger/attempt; the approval id hashes suggestion/approver).
- **Appending**: `final.body = body + "\n" + disclosure` when on; `MAX_BODY` for the *body* becomes `65_536 − 1 − 200` on both the SDK's cap and the Gateway's edited-body check (`malformed_request`, detail naming the disclosure), so the sum never exceeds the schema.
- **Off** = the last `disclosure_decision` row says `off`; then no line, no `data.disclosure` on the approved event; the record answers "since when and who decided".
- **Language outside the five**: SDK path → the loop terminates the delivery with one `ERROR` line `disclosure has no sentence for the language the model answered: <tag>` (non-transient, like the reasoning-budget refusal); Hermes path → `422 hermes_answer_language_unsupported`, counted with the other Hermes-answer codes. `fr-CA` → `fr` (primary subtag) on both paths.
- **Nothing of a contact** in any new log line; vocabulary ("the Companion Gateway", "persona", "network"); `cargo fmt` only; no formatter in the Companion; tests poll with a bound.
